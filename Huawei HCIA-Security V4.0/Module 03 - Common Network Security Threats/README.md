# Module 03 - Common Network Security Threats and Threat Prevention

This module maps out where threats actually show up across an enterprise network: the communication network itself, zone borders, the computing environment, and the management center, and what kind of solution fits each area.

## Topics Covered
- Overview of enterprise network security threats
- Communication network security requirements and solutions
- Zone border security threats and threat prevention
- Computing environment security threats and threat prevention
- Security requirements and solutions of the management center
