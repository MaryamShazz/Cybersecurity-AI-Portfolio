# Key Terms in Module 01

- **CIA Triad** : Confidentiality, Integrity, Availability; the three properties network security is trying to protect.
- **ISMS** : Information Security Management System, the framework ISO 27001 is built around.
- **Classified Protection System** : China's regulatory grading system for information system security requirements.
- **Attack Surface** : every point where an unauthorized user could try to get into or extract data from a system.
- **Zero Trust** : a security model that assumes no user or device is trusted by default, even inside the network perimeter.
