## 💡 Why This Matters

For me, this course is more than a completed certification, it serves as a foundation for the projects I continue to build.

The networking concepts, firewall policies, and NAT technologies strengthen my understanding of how enterprise networks are secured, which directly supports the work documented in my **Huawei Cloud Security Laboratory** and **Cloud Policy Cost & Security Simulator**.

The modules on **AAA** and **identity-based access control** provide the theoretical background for authentication and authorization concepts that appear throughout several of my cloud security projects.

The **Intrusion Prevention System (IPS)** module also gave me a useful reference point for understanding traditional signature based threat detection alongside the AI-assisted detection techniques explored in my **SOC Dashboard**. Rather than replacing one another, these approaches address different aspects of network defense and together provide a broader perspective on threat detection.

Finally, the sections on **cryptography, PKI, and VPN technologies** strengthened my understanding of secure communication, digital certificates, and trust relationships knowledge that supports secure system design even when a project does not directly implement these technologies.
