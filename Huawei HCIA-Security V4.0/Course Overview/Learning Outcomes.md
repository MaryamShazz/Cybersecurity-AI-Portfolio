# Learning Outcomes

- I understand enterprise network security architecture well enough to explain where each control sits and why.
- I understand how a Huawei firewall is deployed and managed through the console, Telnet, SSH, and the Web UI.
- I understand how firewall security policies are written and how stateful inspection works.
- I understand how NAT (source, destination, and NAT Server) is implemented for a small enterprise network.
- I understand firewall high availability and how hot standby is set up using VRRP/HRP/VGMP.
- I understand how intrusion prevention and antivirus are configured on a Huawei firewall.
- I understand how AAA-based user authentication is set up and managed.
- I understand how IPSec and SSL VPNs are configured for site-to-site and remote access use cases.
- I have a working grasp of the cryptography and PKI concepts all of the above actually rely on.
