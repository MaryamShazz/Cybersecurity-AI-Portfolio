# Skills Acquired

## Network Security
- Core network security principles and how the threat landscape has evolved
- Information security standards, including ISO 27001 and the classified protection system
- Enterprise security architecture as a whole, not just individual controls

## Firewall Technologies
- Security zones and how traffic is classified between them
- How security policies are structured and matched
- Stateful inspection and session mechanisms
- ASPF for protocols that open dynamic ports

## Network Address Translation
- Source NAT
- Destination NAT
- Bidirectional NAT
- NAT Server and NAT ALG

## High Availability
- VRRP fundamentals
- HRP (Huawei Redundancy Protocol)
- VGMP groups
- Firewall hot standby, end to end

## Threat Protection
- Intrusion prevention configuration and tuning
- Antivirus at the firewall level
- General threat prevention thinking across zone borders and the management center

## Identity & Access Management
- AAA principles
- User organizational structure and classification
- Authentication process and policy configuration

## Cryptography
- Symmetric and asymmetric encryption
- Hashing algorithms
- PKI structure and working mechanism
- Certificates, CAs, and trust models

## VPN Technologies
- GRE VPN
- IPSec VPN (including site-to-site configuration)
- SSL VPN
- L2TP VPN
